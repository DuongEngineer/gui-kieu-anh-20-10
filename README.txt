Trong ZIP có:
- index.html: trang web lời chúc, trái tim chuyển động, album 7 ảnh.
- images/: các ảnh bạn đã gửi.

CÁCH ĐƯA WEBSITE LÊN MẠNG MIỄN PHÍ BẰNG GITHUB PAGES:
1. Đăng nhập hoặc tạo tài khoản tại https://github.com
2. Tạo repository mới, ví dụ: gui-kieu-anh-20-10
3. Upload index.html và toàn bộ thư mục images (giữ nguyên cấu trúc).
4. Vào Settings > Pages > Build and deployment, chọn Deploy from a branch.
5. Chọn branch main và folder /(root), bấm Save.
6. Chờ GitHub cung cấp địa chỉ dạng https://TEN-TAI-KHOAN.github.io/gui-kieu-anh-20-10/
7. Gửi lại chính xác địa chỉ website đó để tạo mã QR trỏ tới trang.

Nhạc:
Nút “Nghe Chờ Chút” mở kết quả tìm kiếm YouTube để tránh nhúng/tải trái phép bản nhạc có bản quyền.
